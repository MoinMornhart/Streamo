Installation

Streamo is self-hosted. The easiest way is a container on Proxmox VE, created with a single command – but a Raspberry Pi or any other Debian or Ubuntu system works just as well.

Proxmox – one command

Run this in the shell of your Proxmox host:

bash -c "$(curl -fsSL https://raw.githubusercontent.com/MoinMornhart/Streamo/main/scripts/streamo.sh)"

The installer creates an LXC container, installs Node.js and Streamo in it, sets up a systemd service and tells you the address at the end – after two to four minutes Streamo runs at http://<container-ip>:3000.

SettingDefault
SystemDebian 13, unprivileged LXC
CPU / RAM2 cores / 2048 MB
Disk8 GB
NetworkDHCP on vmbr0
Port / autostart3000 / yes

All values can be changed under "Advanced" in the installation dialog.

Raspberry Pi and other Linux machines

The same installer runs on any Debian or Ubuntu system, Raspberry Pi OS included:

sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/MoinMornhart/Streamo/main/scripts/install/streamo-install.sh)"

Use the 64-bit version on the Pi. Streamo needs Node.js 22.13 or newer for the built-in node:sqlite. On 32-bit systems the Node line ends at 22, on 64-bit there is 24. The installer picks the right one by itself and stops with a clear message on an architecture without packages. More in the Raspberry Pi guide (German).

By hand

You need Node.js 22.13 or newer (Node 24 LTS recommended):

git clone https://github.com/MoinMornhart/Streamo.git cd Streamo npm install --omit=dev npm start

Streamo then runs at http://localhost:3000. On first visit a wizard walks you through the setup; the account created there becomes the administrator.

The TMDB key

Titles, images and availability come through the free TMDB API. The instance needs a key for that once: create an account on themoviedb.org/settings/api, request an API key ("Personal / Education" is enough) and enter it during setup or under Settings → TMDB access. It applies to the whole instance; people you invite don't need their own, and once saved it is never shown again.

Updating

In the container a single word is enough – from the Proxmox host, without logging in, use pct exec <CTID> -- update:

update

The update checks whether there is something new, shows the changes, backs up the database (the last five are kept), fetches the new version and checks that the service responds afterwards. If it doesn't, the previous state is restored automatically – code and database.

CommandEffect
updateUpdate, with confirmation
update --checkOnly check whether there's something new
update --yesNo confirmation – for cron jobs
update --forceReinstall even if up to date (repair)

Thanks to the automatic rollback, a nightly update via cron is safe too.

More commands in the container

CommandEffect

streamo admin <name>Grant admin rights (without a name: list all accounts)
streamo registration offen / zuAllow or block accounts without invitation
streamo backup / infoBack up; version, address, state

Backup

Everything important lives in one directory: /opt/streamo/data. Copying it is enough, or use the classic Proxmox backup (vzdump) of the whole container. In the interface, Settings → Data exports library, subscriptions and progress as JSON – handy for moving.
