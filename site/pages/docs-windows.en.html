Windows app

The app shows the same interface as the browser, in its own window – and adds what a browser can't.

⬇️ Download the latest version

First start

Download Streamo-Setup-….exe from the release page and run it. On first start the app asks for the address of your Streamo server – the same one you open in the browser. If Streamo serves HTTPS with a self-signed certificate, you can accept it there for exactly this server.

Windows shows a SmartScreen warning on first start because the installer isn't signed. More info → Run anyway continues.

What the app adds

  • Keeps running in the notification area – closing it hides it in the tray instead of quitting.
  • Notifications about new episodes, including the provider they're on.
  • Start with Windows – if you like.
  • Search with Ctrl+Shift+S from any program.
  • Menus and messages in your system's language – German or English.

Updates

The app keeps itself up to date: shortly after starting and every four hours afterwards it checks, downloads in the background and then asks whether to restart. If you decline, the update is installed the next time you quit. On start it also clears its cache so it reliably shows the new interface after a server update. The tray menu can check for updates by hand at any time and open the update log.
