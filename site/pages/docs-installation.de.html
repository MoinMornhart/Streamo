Installation

Streamo läuft selbst gehostet. Am einfachsten ist ein Container auf Proxmox VE, der mit einem einzigen Befehl entsteht – es geht aber genauso auf einem Raspberry Pi oder jedem anderen Debian- und Ubuntu-System.

Proxmox – ein Befehl

In der Shell des Proxmox-Hosts ausführen:

bash -c "$(curl -fsSL https://raw.githubusercontent.com/MoinMornhart/Streamo/main/scripts/streamo.sh)"

Der Installer legt einen LXC-Container an, installiert Node.js und Streamo darin, richtet einen systemd-Dienst ein und nennt dir am Ende die Adresse – nach zwei bis vier Minuten läuft Streamo unter http://<container-ip>:3000.

EinstellungVorgabe
SystemDebian 13, unprivilegierter LXC
CPU / RAM2 Kerne / 2048 MB
Festplatte8 GB
NetzwerkDHCP an vmbr0
Port / Autostart3000 / ja

Alle Werte lassen sich im Installationsdialog unter „Erweitert“ ändern.

Raspberry Pi und andere Linux-Rechner

Derselbe Installer läuft auf jedem Debian- oder Ubuntu-System, einschließlich Raspberry Pi OS:

sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/MoinMornhart/Streamo/main/scripts/install/streamo-install.sh)"

Auf dem Pi die 64-Bit-Fassung nehmen. Streamo braucht Node.js 22.13 oder neuer für das eingebaute node:sqlite. Auf 32-Bit-Systemen endet die Node-Reihe bei 22, auf 64-Bit gibt es 24. Der Installer wählt die passende von selbst und bricht bei einer Architektur ohne Pakete mit einer klaren Meldung ab. Mehr dazu in der Raspberry-Pi-Anleitung.

Von Hand

Voraussetzung ist Node.js 22.13 oder neuer (Node 24 LTS empfohlen):

git clone https://github.com/MoinMornhart/Streamo.git cd Streamo npm install --omit=dev npm start

Streamo läuft dann auf http://localhost:3000. Beim ersten Aufruf führt ein Assistent durch die Einrichtung; das Konto, das dabei entsteht, wird Administrator.

Der TMDB-Schlüssel

Titel, Bilder und Verfügbarkeiten kommen über die kostenlose TMDB-API. Dafür braucht die Instanz einmal einen Schlüssel: auf themoviedb.org/settings/api ein Konto anlegen, eine API beantragen („Personal / Education“ genügt) und den Schlüssel beim Einrichten oder unter Einstellungen → TMDB-Zugang eintragen. Er gilt für die ganze Instanz; eingeladene Personen brauchen keinen eigenen, und angezeigt wird er nach dem Speichern nie wieder.

Aktualisieren

Im Container genügt ein Wort – vom Proxmox-Host aus ohne Einloggen mit pct exec <CTID> -- update:

update

Das Update sieht nach, ob es etwas Neues gibt, zeigt die Änderungen, sichert die Datenbank (die letzten fünf bleiben), holt die neue Version und prüft, ob der Dienst danach antwortet. Antwortet er nicht, wird automatisch der vorherige Stand wiederhergestellt – Code und Datenbank.

BefehlWirkung
updateAktualisieren, mit Rückfrage
update --checkNur nachsehen, ob es etwas Neues gibt
update --yesOhne Rückfrage – für Cronjobs
update --forceAuch bei aktueller Version neu installieren (Reparatur)

Durch den automatischen Rollback ist auch ein nächtliches Update per Cron ungefährlich.

Datensicherung

Alles Wichtige liegt in einem Verzeichnis: /opt/streamo/data. Kopieren genügt, oder klassisch die Proxmox-Sicherung (vzdump) des ganzen Containers. In der Oberfläche exportiert Einstellungen → Daten Bibliothek, Abos und Fortschritt als JSON – gut für einen Umzug.
