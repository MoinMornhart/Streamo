Windows-App

Die App zeigt dieselbe Oberfläche wie der Browser, in einem eigenen Programmfenster – und kann dazu, was der Browser nicht kann.

⬇️ Neueste Version herunterladen

Erster Start

Auf der Download-Seite Streamo-Setup-….exe herunterladen und ausführen. Beim ersten Start fragt die App nach der Adresse deines Streamo-Servers – derselben, die du im Browser aufrufst. Liefert Streamo HTTPS mit selbstsigniertem Zertifikat aus, lässt sich das dort für genau diesen Server akzeptieren.

Windows zeigt beim ersten Start eine SmartScreen-Warnung, weil der Installer nicht signiert ist. Über Weitere Informationen → Trotzdem ausführen geht es weiter.

Was die App zusätzlich kann

  • Im Infobereich weiterlaufen – beim Schließen verschwindet sie in den Tray, statt sich zu beenden.
  • Benachrichtigungen bei neuen Episoden, samt Anbieter, bei dem sie laufen.
  • Mit Windows starten – auf Wunsch.
  • Suche per Strg+Umschalt+S aus jedem Programm.
  • Menüs und Meldungen in der Sprache des Systems – Deutsch oder Englisch.

Updates

Die App hält sich selbst aktuell: kurz nach dem Start und danach alle vier Stunden sieht sie nach, lädt im Hintergrund und fragt dann, ob neu gestartet werden soll. Wer ablehnt, bekommt das Update beim nächsten Beenden. Beim Start leert sie außerdem ihren Zwischenspeicher, damit sie nach einem Server-Update sicher die neue Oberfläche zeigt. Über das Tray-Menü lässt sich jederzeit von Hand nach Updates suchen und das Update-Protokoll öffnen.
